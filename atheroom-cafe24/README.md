# 엣더룸 · 상품 작업실

사진과 상품 정보를 올리고, 승인한 형식으로 상세페이지를 준비한 뒤 카페24에 등록하는 개인 작업실입니다.

**현재 구성은 Vercel 화면 + 켜져 있는 Mac의 서버·저장소 + ChatGPT 구독의 Codex입니다.** Supabase나 유료 AI API는 사용하지 않습니다. 실제 카페24 비공개 상품 등록까지 확인했으며, 항상 켜져 있는 독립 서버로 배포한 상태는 아닙니다.

## 사용하기

1. Mac을 켜고 인터넷에 연결합니다.
2. 이 폴더의 **온라인 작업실 열기.command**를 실행하고 연결 반영이 끝날 때까지 기다립니다.
3. [온라인 상품 작업실](https://atheroom-cafe24.vercel.app)에 로그인합니다. 도우미 터미널 창은 계속 열어둡니다.
4. 새 상품에 사진과 확인한 정보를 넣고 필요하면 Codex 초안을 생성합니다.
5. 사진 용도·순서, 상품군, 금액, 옵션, 문구를 확인하고 저장합니다. 필수 항목을 해결하고 검수한 뒤 등록합니다.
6. 완료 화면의 카페24 상품 번호와 링크로 결과를 확인합니다. 새 상품은 비진열·판매 중지로 등록됩니다.
7. 진행 중인 작업이 없으면 도우미 창에서 Control+C로 종료합니다.

Mac이 꺼지거나 잠자기에 들어가면 조회·사진·저장·AI·등록을 사용할 수 없습니다. 재실행할 때 터널 연결과 Vercel 배포에 시간이 걸릴 수 있습니다. 저장하지 않은 입력은 보관되지 않을 수 있습니다.

## 상품 작성 기준

- 상세페이지는 메인 사진, 운영자 설명, 착용·제품·디테일 사진 순서입니다. 자동으로 덧붙이는 소재·사이즈 및 배송·교환/반품 텍스트는 생략합니다.
- 사진 사이와 텍스트 뒤 다음 사진 앞에는 네 줄(96px) 간격을 둡니다. 상세 텍스트는 11px, comment와 detail info 제목만 굵게 표시합니다. material은 일반 글씨입니다.
- **상품 간략 설명에는 입력한 detail info 제목부터 끝까지 글과 줄바꿈을 그대로 복사합니다. HTML 서식이나 안내 문장을 추가하지 않습니다.** 직접 작성한 블록이 없을 때만 상품 정보와 공통 안내로 일반 텍스트를 만듭니다.
- 옵션명은 COLOR, SIZE, 값은 소문자입니다. 추가 이미지는 메인과 메인과 다른 첫 착용 사진만 넣습니다. 모든 품목은 재고관리 사용 안 함으로 등록합니다.
- 사진 배치 차이 동의와 필수 정보 확인은 별개입니다. 운영자가 쓴 글의 문체 때문에 등록을 막지 않습니다. 검수 뒤 수정하면 다시 검수합니다.

전체 규칙과 예외는 [AGENTS.md](AGENTS.md)의 ‘최신 업무 규칙’을 기준으로 합니다.

## 체험 실행과 데이터 보관

`작업실-열기.command` / `start-local.sh`는 온라인 운영과 다른 **로컬 체험 환경**입니다. 기본 화면은 `http://127.0.0.1:3011/`이며 체험 등록은 실제 카페24에 상품을 만들지 않습니다. 기본적으로 AI는 실제 Codex 구독을 사용하고, `DEMO_AI_ENABLED=false`로 실행하면 AI도 모의 동작합니다.

운영 DB·처리된 사진·인증 설정은 Git에서 제외된 `.local-cache/online/`에 있습니다. GitHub에 코드를 저장해도 이 데이터는 백업되지 않습니다. 새 Mac에서는 안전한 데이터 이전과 비공개 설정이 필요합니다. 비밀번호와 인증 키를 채팅이나 저장소에 넣지 마세요.

`compose.yaml`, PostgreSQL/S3 및 `deploy/railway/` 자료는 다른 실행 방식의 참고입니다. 현재 개인 Mac 운영에 해당 서비스를 추가할 필요는 없습니다. 스마트스토어 전체 연동, 새 OAuth 반환 주소의 재승인, 상시 가용성과 새 Mac 자동 설치는 아직 별도 확인이 필요합니다.
