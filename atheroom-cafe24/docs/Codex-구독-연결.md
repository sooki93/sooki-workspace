# 맥에서 Codex 구독으로 사용하기

현재 선택한 운영 방향은 맥에서 실행하는 작업실과 ChatGPT 구독에 포함된 Codex입니다. 별도 API 키나 Railway 서버를 개설하지 않았습니다. 2026-09-10 실제 사진 분석과 초안 생성까지 확인했습니다. 카페24 실제 등록 연결은 다음 단계입니다.

## 사용 순서

1. 작업실을 열고 새 상품을 만듭니다. 기존에 열어둔 화면은 새로고침해야 변경된 버튼이 보입니다.
2. 사진을 올리고 확인한 소재·사이즈 등 정보를 입력합니다.
3. **Codex로 초안 만들기**를 누릅니다. 맥과 인터넷 연결을 유지합니다.
4. 사진 용도·상품군·문구를 확인하고 검수합니다. 현재의 **체험 등록하기**는 카페24에 상품을 만들지 않습니다.

운영 설정의 **AI 연결 확인**은 로그인 상태만 확인하며 분석 요청을 보내지 않습니다. 사진 분석·초안 작성은 실제 구독 사용량을 소비합니다. 상품의 사진에서 상품군을 고른 뒤 선택된 형식으로 설명을 만들기 위해 현재 상품당 두 번 호출합니다.

## 한도와 연결 문제

구독 한도 또는 로그인 문제 응답을 받으면 작업은 **AI 작업 대기**로 보관됩니다. 한도 회복이나 로그인 후 상품의 **다시 시작**을 누릅니다. 자동으로 반복 요청하거나 API로 전환하지 않습니다. 다시 시작할 때 현재 저장된 입력으로 새 요청을 만들므로 이전에 분석한 일부 단계는 다시 실행할 수 있습니다. 기존 상품 형식 분석의 대기는 ‘우리 쇼핑몰 형식’의 **다시 시작**으로 재요청합니다.

구독의 한도·크레딧 정책은 계정에 적용되는 정책을 따릅니다. 이 앱은 추가 크레딧 구매나 자동 충전을 설정하지 않습니다. 계정 소유자가 다른 화면에서 설정한 추가 사용 과금 정책까지 앱이 변경하거나 통제하는 것은 아닙니다.

## 실행 설정

`start-local.sh` 및 ‘작업실-열기.command’는 다음 설정으로 시작합니다.

```dotenv
AI_PROVIDER=codex
DEMO_MODE=true
DEMO_AI_ENABLED=true
```

쇼핑몰 연결·기존 형식 체험 자료·등록은 체험으로 유지하고 사진 분석과 초안만 실제 Codex를 사용합니다. `DEMO_AI_ENABLED=false`로 시작하면 AI 호출도 없는 체험입니다. 실제 쇼핑몰 연결을 위해 체험 DB의 실행 모드만 바꾸지 마세요. 운영 인증과 별도 데이터 보관 설정이 필요합니다.

Codex 설치 경로는 PATH에서 찾고, 맥의 ChatGPT/Codex 앱에 포함된 실행 파일도 확인합니다. 필요할 때만 `CODEX_BINARY`에 절대 경로를 지정합니다. `codex login status`가 ChatGPT 로그인을 나타내야 하며 API 로그인은 거부합니다. 로그인 파일을 복사하거나 GitHub에 저장하지 않습니다.

실행은 `codex exec --ignore-user-config --ephemeral --sandbox read-only`를 사용하고 ChatGPT 로그인을 강제합니다. 입력은 명령 문자열에 섞지 않고 표준 입력으로 전달하며, 이미지와 JSON 스키마는 작업별 임시 파일로 전달합니다. 결과는 서버가 다시 검증합니다. 기본 응답 제한 시간은 300초이며 `CODEX_TIMEOUT_SECONDS`로 15~900초 범위에서 조정합니다. 제한 시간 초과 시 자식 프로세스를 종료하고 임시 파일을 정리합니다.

현재 Codex는 맥에서만 실행합니다. 기존 Docker 이미지에는 Codex와 사용자 로그인이 포함되어 있지 않습니다. 작업실의 체험 로그인을 공개 인터넷에 노출하지 마세요. 카페24 연결을 위한 HTTPS 공개 전에는 운영자 인증을 먼저 적용해야 합니다.
