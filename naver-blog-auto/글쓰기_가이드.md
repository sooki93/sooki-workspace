# 헬로뽀숑 블로그 글쓰기 가이드

매일 글을 쓸 때 이 가이드를 기준으로 초안을 만든다. 첫 글(백일선물)을 쓰며 확정한 규칙과 피드백을 모두 담았다.

## 진행 방식 (하루 한 편)
1. 주제 정하기: `posts/_주제목록.md`에서 다음 주제를 고르거나, 그날 정한 주제로 쓴다
2. 초안 한 번에 작성: 제목 후보 3개(추천 1개) + 본문 + 사진 배치 + 캡션 + 태그 10개 + 자체 검증 결과
3. 검토·수정: 고칠 곳만 받아서 고친다. 사용자가 직접 고친 문장은 **그대로** 쓰고 덧붙이지 않는다
4. 글 파일 만들기: `posts/YYYY-MM-DD_주제.md` (front matter `images: YYYY-MM-DD_주제`). 사진 폴더 `~/sookhee-image/헬로뽀숑이미지/블로그/YYYY-MM-DD_주제/`를 만들고 **항상 Finder로 열어준다** (`open` 또는 대시보드 [사진 폴더 열기]). 사진 보관함 `~/sookhee-image/헬로뽀숑이미지/`에 맞는 사진이 있으면 1.jpg…로 복사해두고, 나머지는 사용자가 번호대로 넣는다
5. 발행: 사용자가 대시보드에서 [바로 발행]을 두 번 눌러 발행

## 브랜드 사실 (이 범위 밖의 스펙·수치는 쓰지 않는다)
- 헬로뽀숑(hellopouchon.com), 925 실버 어린이 주얼리 브랜드. 직접 운영하는 브랜드 블로그 (제3자·후기인 척 금지)
- 운영자 주얼리 업계 10년 이상, 직접 디자인 + 숙련된 세공사 완성
- 재고 없이 주문 후 하나씩 제작. 제작 기간은 제품마다 다르고 단정하지 않는다
- 사전 각인 시안 서비스: 주문 전 각인 결과 미리 확인
- 미아방지: **텍스트 각인**(이름 + 보호자 연락처 최대 2개, 전 제품) / **QR 각인**·QR 안심 서비스(**OUR HOME 컬렉션만**, 보호자 번호 대신 안심번호로 연결)
- 제품: OUR HOME 컬렉션, Guardian Bunny 목걸이, TINY WAVE 팔찌, 드로잉 하트 목걸이, 드로잉 팔찌
- OUR HOME: '우리의 집'이라는 뜻, 펜던트에 아이 이름을 새겨 아이만의 작은 집. 앞면 이름 + 별빛·탄생석. 목걸이 3cm 연장 체인 (팔찌는 제품마다 다름 → 쓰지 않는다)
- 925 실버는 "은 함량 92.5%의 합금"까지만. 안전성·건강 표현 금지
- 대표번호(1555-1291) 노출 가능
- 가격은 본문에서 뺀다
- 권장 착용 연령 없음. 특정 나이 제시 금지

## 검색 노출 (네이버 DIA·C-Rank)
- 메인 키워드 1개 + 서브 키워드 3~5개. 검색량은 추정하지 않고 사용자가 키워드도구로 확인
- 메인 키워드: 제목 맨 앞, 도입 첫 두 문단, 본문 중간, 마무리. **소제목 빼고 본문 문장에서만 5회 이상** (2026-10-17 사용자 기준)
- 한 문단에 같은 키워드 2번 이상 금지, 나열 금지
- 검색 의도에 대한 답을 본문 앞쪽(도입 둘째 문단)에 둔다
- 분량 공백 포함 1,800~2,500자, 문단 2~4줄, 브랜드 비중 30% 이내, 자사몰 링크는 하단 1개

## 제목 (6가지 기법 중 1~2개 조합, 메인 키워드 맨 앞, 30자 안팎, 숫자·물음표 활용)
상식파괴 / 숫자의 원칙 / 자아흠집내기 / 금지와 위협 / 권위자 인용 / 궁금증 유발
- **검색하는 사람의 실제 고민에서 출발한다.** 브랜드가 하고 싶은 말로 만들면 공감이 안 된다 (예: 백일선물 검색자는 주는 사람이 많고, 겹침·금반지 부담·받는 엄마 반응을 고민)
- 노골적인 제품 홍보 제목 금지 ("금반지 대신 은목걸이" 류는 거절됨)
- 근거 없는 관찰 단어 금지: "공통점", "~하는 부모가 늘어난" 등 → "기준", "조건"처럼 근거가 필요 없는 말
- 자아흠집내기·금지와 위협은 공포 마케팅이 되지 않을 만큼만 약하게. "100% 후회" 같은 표현 금지

## 문장 톤 (첫 글에서 받은 피드백)
- 따뜻하고 차분한 정보형, ~요체. 이모지는 소제목에 최대 1개
- **딱딱한 문서체 금지, AI가 쓴 티가 나면 안 된다.** 말하듯 쓴다: "~거든요", "~잖아요", "~고요", 독자에게 묻기("같이 볼까요?"), 짧은 문장 섞기, "~랑" 같은 구어. "결론부터 말하면", "하나씩 정리해볼게요", "~하는 방식이에요"만 반복되는 나열체는 피한다
- 구어체여도 가볍게 떠넘기는 말투는 금지: "뭐가 더 좋다기보다는 ~고르시면 돼요" ✗ → 차이를 정확히 짚는다. "~면 돼요" 반복 금지
- 목록은 꼭 필요한 항목만. 비슷한 항목을 억지로 늘리지 않는다
- 1인칭은 "만드는 사람" 시점만. 육아 경험담·후기·수치 지어내기 금지
- **꾸미는 문장 금지**: "주얼리는 받는 날보다 함께하는 시간이 더 길어요", "~인 셈이에요"처럼 그럴듯하지만 실제로는 아무도 하지 않는 말은 쓰지 않는다
- **주얼리에 보관 물건 표현 금지**: "상자에 넣어두었다가 꺼내 준다"는 어색하다. 주얼리는 하는 물건
- 문단끼리 앞 문장을 이어받아 흐르게. 갑자기 브랜드로 넘어가지 않는다
- 만드는 사람의 고민(변색, 도금)은 검색자가 공감하지 않는다. 검색자의 고민(유치해 보일까, 오래 할까, 아이가 좋아할까)으로 쓴다
- 브랜드 연결은 특정 제품 컨셉(예: 집 모양)보다 "아이 이름이 곧 디자인이 되는 감도 있는 주얼리"처럼 브랜드 전체로
- 단단하게 맺는 문장은 "~입니다"도 가능 (예: "미아방지 목걸이는 선택이 아닌 필수입니다")

## 주제별 규칙
- 백일·돌·출산선물: "미리 준비해두는 선물" 프레임. 영아가 지금 착용하는 장면·표현 금지. 각인으로 그 시기의 기록이 남는다는 기념 가치
- 미아방지: 명칭은 "각인형/QR형"이 아니라 **"텍스트 각인/QR 각인"**. 둘을 구분하고, QR은 OUR HOME만. 텍스트 각인은 별도 등록 없이 받자마자 쓸 수 있어 간편함, 연락처 2개. QR은 스캔이 어려우면 대표번호+고유번호 5자리로 연결되도록 설계. 상황은 불안이 아니라 일상(나들이, 여행, 놀이공원·마트, 등원 첫날). 핵심은 안심·연결·개인정보 보호

## 절대 금지
극단적 과장("100% 안전", 절대, 무조건, 최고, 1위, 필수템, 역대급, 완벽) / 공포 마케팅(실종 통계·사례) / KC 인증 언급 / 건강·효능 표현 / 타 브랜드 비방·직접 비교 / 지어낸 후기·수치·스펙

## 사진
- 각인 디테일, 선물 포장, 사전 각인 시안 화면, 조금 큰 아이의 착용 컷 위주. 영아 착용 컷 금지
- 사진 보관함은 `~/sookhee-image/헬로뽀숑이미지/` (파일명 `YYMMDD_헬로뽀숑_NN`). 열어보고 고르며, 최근 글에 쓴 사진은 되도록 피한다
- 캡션은 한 줄, 사진 내용과 맞게
