# Rhino 전용 작업공간

이 폴더는 **참고 사진·스케치·치수·기존 모델 등을 기반으로 새로운 Rhino 8 모델을 만드는 작업**을 주로 수행하는 전용 작업공간입니다. 기존 형상 수정, Grasshopper 및 관련 스크립트 작업도 지원합니다. 상위 저장소에는 다른 프로젝트가 있으므로 Rhino 작업은 기본적으로 `rhino/` 안에서 진행합니다. 다른 프로젝트의 파일·설정·배포는 변경하지 않습니다.

## 작업 원칙

- 기본 흐름은 **참고 자료 파악 → 새 모델 구성 → 형상과 치수 검증 → 새 파일 저장 및 미리보기 전달**입니다. 기존 파일을 제공받았다는 이유만으로 그 파일의 일부를 수정하는 작업으로 한정하지 않습니다.
- 사용자가 기존 모델 수정을 명시하면 해당 모델과 요청한 부위만 수정합니다. 참고 자료와 요청 외의 모델은 보존합니다.
- 실행 가능한 요청은 준비부터 모델링, 검증, 저장까지 진행합니다. 이미 허용된 작업이나 일상적인 모델링 선택에 대해 반복해서 확인을 요청하지 않습니다.
- 원하는 결과, 참고할 형상, 주요 치수와 용도를 자료에서 먼저 파악합니다. 결과에 영향을 주는 모호함만 짧게 질문하고, 그동안 자료 확인 등 독립적인 준비를 진행합니다.
- 사진에 없는 뒷면 구조나 치수는 확정된 사실로 취급하지 않습니다. 제공된 치수를 우선하고, 치수가 없으면 참고 자료의 비례를 바탕으로 작업용 크기를 정해 알립니다. 결합 부품과의 호환성 등 정확한 치수가 필요한 부분은 확인합니다.

## 신규 모델링의 기본 흐름

- 새 문서 또는 별도 MCP 슬롯에 모델을 만듭니다. 기존 모델의 형상을 활용하는 경우에는 원본을 보존하고 필요한 객체를 복제하거나 파일 사본에서 시작합니다. 사진만으로 만드는 작업에 불필요한 원본 `.3dm`을 요구하지 않습니다.
- 참고 자료에서 전체 윤곽, 비례, 단면, 대칭 여부, 연결 구조와 표면 디테일을 파악합니다. 재현할 특징과 새롭게 설계할 부분을 구분합니다.
- 문서 단위와 허용오차를 정하고 전체 크기와 주요 구조부터 만듭니다. 곡률, 두께, 필렛, 홈과 장식 등 세부 형상은 기본 형태를 확인한 뒤 추가합니다.
- 참고 자료, 보조 곡선, 작업 중 형상, 완성 모델은 필요에 따라 레이어로 구분합니다. 완성 모델만 확인하거나 내보낼 수 있도록 구성합니다.
- 반복되는 형상이나 치수 조절이 예상되면 재사용 가능한 Python/C# 스크립트 또는 Grasshopper 정의를 활용합니다. 단순한 일회성 작업에 불필요한 자동화 구조를 만들지는 않습니다.
- 새 결과물은 모델명과 버전을 알아볼 수 있는 별도 파일로 저장합니다. 예: `부채꼴고리_펜던트_v01.3dm`. 신규 모델에 관성적으로 `수정`이나 `사본`이라는 이름을 붙이지 않습니다.

## 기존 모델 수정 및 원본 보존

- 기존 모델을 수정할 때는 **원본을 보존하고 사본에서 편집**합니다. 원본 직접 수정은 사용자가 명시적으로 요청한 경우에만 합니다.
- Desktop 등 외부 경로의 파일을 작업에 사용할 때는 필요한 자료를 이 작업공간으로 복사합니다. 사용자가 별도 저장 위치를 지정했다면 그 지시를 따릅니다.
- 수정본은 모델과 수정 내용을 알아볼 수 있게 지정합니다. 예: `통통라운드(고리수정_사본).3dm`. 신규·수정 작업 모두 같은 이름의 파일이 있으면 내용을 확인하고, 별도 버전이 필요할 때 `_v02` 또는 날짜를 붙입니다.
- 사용자가 다른 문서를 열어 놓았다면 그 문서를 비우거나 닫지 않습니다. 미저장 작업을 버리지 않습니다.
- 수정 전 형상을 사본 안에 보관할 때는 `수정전_<대상>_보관`처럼 명확한 숨김 레이어를 사용합니다. 완성 형상과 겹쳐 표시되거나 출력 대상에 섞이지 않도록 확인합니다.
- 원본 보존이 요청된 작업은 가능한 경우 작업 전후 파일 해시를 비교합니다.

## Rhino MCP 사용

- 시작할 때 연결 상태와 실행 중인 슬롯을 조회하고 대상 문서를 확인합니다. 이전 대화의 슬롯 이름·포트·객체 GUID가 계속 유효하다고 가정하지 않습니다.
- 여러 문서가 있으면 후속 호출에 대상 슬롯을 명시합니다. 문서 이름, 경로, 객체 수와 경계 상자를 확인한 뒤 편집합니다.
- `open_doc`는 파일을 현재 문서에 가져오는 동작입니다. `clearFirst`는 기존 객체를 지우므로 사용자 문서에 무심코 적용하지 않습니다. 가져온 뒤 단위와 허용오차도 확인합니다.
- Python/C#에서는 MCP가 주입한 `__rhino_doc__`를 대상 문서로 사용합니다. `RhinoDoc.ActiveDoc`, `scriptcontext.doc`, `rhinoscriptsyntax`의 암묵적인 활성 문서에 의존하지 않습니다.
- 연결 오류가 나면 슬롯을 다시 조회하고 실제 문서 상태를 확인합니다. 생성·삭제·가져오기 호출이 실패로 표시되어도 일부 작업이 수행되었을 수 있으므로 변경 호출을 무조건 재실행하지 않습니다.
- Python 호출의 출력이 비어 있어도 실행 결과가 없다고 단정하지 않습니다. 객체 조회 또는 임시 JSON 보고서로 결과를 확인합니다. 중간 진단 파일은 임시 경로에 둡니다.
- 숨김·표시 변경은 잠금 상태에 따라 실패할 수 있습니다. 반환값과 실제 뷰포트를 확인하고 임시 변경은 복원합니다.

## 모델링과 검증

- 모델링 시작 시 문서 단위, 절대 허용오차, 목표 크기와 연결 구조를 확인합니다. 기존 형상을 활용할 때는 객체와 레이어도 확인하고, 원본 자료의 단위를 임의로 해석하거나 전체 크기를 바꾸지 않습니다.
- 가능하면 편집 가능한 Rhino 형상으로 작업합니다. 메쉬 변환, 전체 결합, 파괴적인 정리는 목적에 필요할 때만 수행합니다.
- 솔리드를 만드는 작업은 형상의 유효성, 닫힘 여부, 열린 모서리 및 불리언 연산 결과를 확인합니다. 의도된 열린 곡면은 솔리드가 아니라는 이유만으로 오류로 취급하지 않습니다.
- 모델의 용도에 맞게 두께, 간격, 구멍과 부품 간 간섭을 확인합니다. 주얼리 고리는 체인 통과 공간과 펜던트 접합부를, 움직이는 부품은 분리 상태와 작동 공간을 확인합니다. 움직여야 하는 부품을 임의로 합치지 않습니다.
- 참고 자료와 비교하는 정면 및 입체감을 확인할 수 있는 측면 또는 사시도에서 결과를 검토합니다. 참고 이미지나 다른 객체가 모델을 가리지 않는지 확인합니다.
- 미리보기는 실제 제작한 모델을 Rhino에서 캡처합니다. 생성 이미지나 보정된 그림을 실제 모델의 검증 결과로 제시하지 않습니다.
- 닫힌 솔리드 확인만으로 주조·출력·제작 적합성을 확정하지 않습니다. 제작용 검토를 요청받으면 사용 공정과 제공된 치수 조건에 맞게 별도로 확인합니다.

## 파일과 참고 이미지 관리

- `.3dm`, 미리보기, 해당 모델에 필요한 이미지와 재사용할 스크립트를 이 폴더에서 관리합니다. 현재 파일을 정리 목적으로 임의 이동하거나 이름을 바꾸지 않습니다.
- 파일이 많아지면 새 작업 단위로 하위 폴더를 만들 수 있습니다. 기존 파일을 일괄 재배치할 필요는 없습니다.
- Picture/텍스처가 외부 파일을 참조하면 해당 이미지도 함께 보관합니다. `<모델명>_embedded_files/` 같은 동반 폴더를 누락하지 않습니다.
- 동반 이미지 복사만으로 참조 경로가 수정되었다고 가정하지 않습니다. 다른 경로로 옮긴 파일을 전달할 때 이미지 포함 여부나 참조 해석을 확인하고, 필요한 경우 사본의 참조를 수정합니다.
- 저장 후 파일을 다시 읽어 완성 모델의 존재, 형상 상태와 주요 치수를 확인합니다. 기존 파일에서 시작한 작업은 보존해야 할 객체와 참고 자료가 유지되는지도 확인합니다.
- Git 커밋·푸시는 사용자가 요청한 범위에서 수행합니다. 큰 바이너리를 다룬다는 이유로 저장소 전체의 Git LFS나 추적 규칙을 임의로 변경하지 않습니다.

## 결과 전달

- 무엇을 바탕으로 어떤 모델을 만들었는지, 주요 치수와 수행한 검증을 한국어로 간결하게 설명합니다. 기존 모델 수정 작업은 변경 부위와 원본 보존 여부도 설명합니다.
- 최종 `.3dm`과 확인한 미리보기의 클릭 가능한 로컬 경로를 제공합니다.
- 확인하지 못한 부분이나 결과에 중요한 가정이 있으면 구체적으로 밝힙니다. 완료하지 않은 검증을 완료했다고 보고하지 않습니다.

## 기존 작업 자료

- `통통라운드(고리수정_사본).3dm`: 참고 사진 바로 왼쪽 펜던트의 고리를 수정한 사본입니다.
- `통통라운드_고리수정_미리보기.png`: 수정 모델과 참고 사진의 정면 비교입니다.
- `통통라운드(고리수정_사본)_embedded_files/`: 해당 모델의 참고 이미지입니다.
- 사본의 `수정전_오른쪽모델_보관` 레이어에는 수정 전 대상 형상이 보관되어 있습니다.

이 목록은 이전 수정 작업의 탐색을 돕기 위한 기록이며, 신규 모델링의 기본 대상이나 템플릿이 아닙니다. 새 요청에 지정된 자료를 기준으로 작업하고 파일과 문서의 실제 상태를 확인합니다.
